# راه‌اندازی Ollama برای TheraSim

این راهنما برای اجرای محلی Ollama و داده‌های آموزشی کاملاً داستانی است.
Ollama و وزن‌های مدل همراه TheraSim بسته‌بندی نمی‌شوند.
بستهٔ قابل‌حمل TheraSim برای Windows x64 است و در این بررسی فقط روی
Windows 11 Pro x64 آزمایش شده است. راهنمای نصب Ollama برای macOS و Linux
به معنی تأیید پشتیبانی برنامهٔ TheraSim در آن سیستم‌عامل‌ها نیست.

## ۱. Ollama چیست؟

Ollama مدل‌های زبانی را روی رایانهٔ شما دریافت و اجرا می‌کند و یک API محلی
در اختیار برنامه‌ها می‌گذارد. نشانی پیش‌فرض Ollama در TheraSim برابر است با
`http://127.0.0.1:11434/v1`. وقتی حالت فقط محلی فعال باشد، نشانی‌های مدل
دوردست مسدود می‌شوند. حتی هنگام استفاده از مدل محلی نیز اطلاعات واقعی بیمار
یا مراجع را وارد نکنید.

## ۲. نصب و بررسی Ollama

### ویندوز

۱. نصب‌کنندهٔ ویندوز را از
[ollama.com/download/windows](https://ollama.com/download/windows) دریافت و
اجرا کنید.
۲. پنجرهٔ تازه‌ای از PowerShell باز کنید و دستورهای زیر را اجرا کنید:

```powershell
ollama --version
ollama list
```

۳. پاسخ‌گویی سرویس محلی را بررسی کنید:

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:11434/api/version"
Invoke-RestMethod -Uri "http://127.0.0.1:11434/api/tags"
```

### macOS

Ollama را از [صفحهٔ رسمی دریافت](https://ollama.com/download) نصب و برنامه را
باز کنید. سپس در Terminal دستورهای `ollama --version` و `ollama list` را
اجرا کنید. سرویس محلی را با نشانی
`curl http://127.0.0.1:11434/api/version` بررسی کنید. برای توقف یا شروع دوباره،
برنامهٔ Ollama را ببندید یا باز کنید.

### Linux

دستورهای [راهنمای رسمی نصب Linux](https://github.com/ollama/ollama/blob/main/docs/linux.md)
را دنبال کنید. سپس `ollama --version` و `ollama list` را اجرا کنید. اگر
Ollama به‌صورت سرویس systemd نصب شده است، وضعیت را با
`systemctl status ollama` ببینید و برای شروع/توقف سرویس از
`sudo systemctl start ollama` و `sudo systemctl stop ollama` استفاده کنید.
در غیر این صورت `ollama serve` را در یک Terminal اجرا کنید و برای توقف
`Ctrl+C` بزنید. نشانی `curl http://127.0.0.1:11434/api/version` را بررسی کنید.

دستورهای ویندوز در این رایانه با Ollama نسخهٔ ۰٫۳۴٫۴ بررسی شده‌اند. نحو
دستورها با راهنمای CLI نصب‌شده مطابقت دارد؛ ممکن است نسخه‌های دیگر راهنمای
متفاوتی نمایش دهند.

## ۳. دریافت و اجرای مدل

دریافت اولیهٔ مدل معمولاً به اینترنت نیاز دارد. TheraSim مدل را خودکار
دریافت نمی‌کند. برچسب دقیق مدل، مجوز و نیاز منابع را بررسی کنید و فقط در
صورت تصمیم خود آن را دریافت کنید. برای نمونه:

```powershell
ollama pull qwen2.5:3b
ollama list
ollama run qwen2.5:3b
```

مدل `qwen2.5:3b` در چهار اجرای داستانی PatientAgent، شامل دو سناریوی انگلیسی
و فارسی با دو بار تکرار، روی یک رایانهٔ Windows آزمون طرح‌واره را گذراند.
مجوز نمایش‌داده‌شده برای آن توافق‌نامهٔ پژوهشی Qwen است؛ پیش از استفاده،
شرایط آن را بررسی کنید. گزارش EvaluatorAgent در سه مورد از چهار اجرای خروجی
ساخت‌یافته پذیرفته شد و یک مورد به‌دلیل نقل‌قول نامعتبر رد شد. بنابراین این
مدل **برای ارزیابی پیشنهاد نمی‌شود**. مدل Gemma آزمایش‌شده نیز در ارزیابی
ناموفق بود. این نتایج فقط برای همین برچسب‌ها و سخت‌افزار هستند و توصیهٔ عمومی
محسوب نمی‌شوند؛
[گزارش ارزیابی مدل‌ها](LOCAL_AI_MODEL_EVALUATION.md) را ببینید.

پس از نمایش ورودی تعاملی، یک پیام کاملاً داستانی بنویسید و برای خروج
`Ctrl+C` را فشار دهید. مدل بارگذاری‌شده و محل اجرای آن را بررسی کنید:

```powershell
ollama ps
nvidia-smi --query-gpu=name,memory.total,memory.used --format=csv
```

دستور `ollama ps` نشان می‌دهد مدل روی GPU اجرا می‌شود یا بخشی از آن روی CPU
قرار دارد. استفاده از GPU به درایور، حافظهٔ آزاد، مدل و اندازهٔ متن زمینه
بستگی دارد؛ لازم نیست فرض کنید تمام مدل باید در حافظهٔ VRAM جا شود. برای
توقف یا حذف مدل ابتدا برچسب دقیق را با `ollama list` بررسی کنید:

```powershell
ollama stop gemma-4-E2B:latest
ollama rm gemma-4-E2B:latest
```

`ollama rm` فایل‌های مدل را حذف می‌کند و ممکن است برای استفادهٔ دوباره به
دریافت مجدد نیاز باشد. اگر به نسخهٔ آفلاین نیاز دارید این دستور را اجرا
نکنید. `ollama stop` فقط مدل در حال اجرا را از حافظه خارج می‌کند.

## ۴. تنظیم TheraSim

۱. Ollama را اجرا کنید و مطمئن شوید مدل در `ollama list` دیده می‌شود.
۲. TheraSim را اجرا کنید و به حساب بازبین محلی وارد شوید.
۳. بخش **تنظیمات** را باز و **Ollama** را انتخاب کنید:
   - میزبان: `127.0.0.1`
   - درگاه: `11434`
   - مسیر نشانی پایه: `/v1`
   - مدل: `qwen2.5:3b` یا برچسب دقیق یکی از مدل‌های نصب‌شده
   - در صورت نیاز برای نقش مراجع و ارزیاب مدل‌های جدا انتخاب کنید؛ خالی
     گذاشتن هر فیلد از مدل عمومی استفاده می‌کند.
۴. برای اجرای محلی، حالت **فقط محلی** را روشن نگه دارید.
۵. **آزمایش اتصال** را بزنید. در صورت موفقیت، اتصال ارائه‌دهنده و اگر سرور
   پشتیبانی کند مدل انتخاب‌شده نمایش داده می‌شود.
۶. پس از ذخیرهٔ تنظیمات، TheraSim را دوباره راه‌اندازی کنید؛ عامل‌های
   شبیه‌سازی، تنظیمات ارائه‌دهنده را هنگام شروع برنامه می‌خوانند.

در فضای کاری مدل، دکمهٔ **ارزیابی این دستگاه** اطلاعات محلی سیستم‌عامل،
پردازنده، حافظه، دیسک، کارت NVIDIA شناسایی‌شده و نسخهٔ Ollama محلی را در صورت
دسترس‌بودن نشان می‌دهد. اطلاعات سخت‌افزار ارسال نمی‌شود و مدلی خودکار انتخاب
یا دریافت نمی‌شود. تشخیص GPU فعلاً فقط NVIDIA را با `nvidia-smi` بررسی
می‌کند؛ GPUهای Intel و AMD هنوز شناسایی نمی‌شوند. دسته‌بندی منابع تخمینی است
و سازگاری مدل را تضمین نمی‌کند.

نشانی کامل برابر `http://127.0.0.1:11434/v1` است. API بومی Ollama از مسیر
`/api` استفاده می‌کند، اما کلاینت ارائه‌دهندهٔ TheraSim از رابط سازگار با
OpenAI در مسیر `/v1` بهره می‌برد. فهرست مدل‌ها را می‌توانید این‌طور بررسی
کنید:

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:11434/v1/models"
```

میزبان، درگاه، مسیر و مهلت پاسخ را در **تنظیمات** یا فایل مجاز
`%LOCALAPPDATA%\TheraSim\config.env` تغییر دهید. نام تنظیم مهلت پاسخ
`THERASIM_LLM_TIMEOUT` است و باید بین ۱ تا ۶۰۰ ثانیه باشد. نشانی HTTP
غیرمحلی پذیرفته نمی‌شود. برای استفاده از نشانی HTTPS دوردست باید حالت فقط
محلی را خاموش و اتصال دوردست را صریحاً تأیید کنید؛ فقط وقتی از مقصد ارسال
متن آگاه هستید از این گزینه استفاده کنید.

## ۵. میزبان یا درگاه سفارشی Ollama

راهنمای CLI، متغیر `OLLAMA_HOST` و مقدار پیش‌فرض
`127.0.0.1:11434` را اعلام می‌کند. اگر عمداً درگاه محلی دیگری می‌خواهید،
ابتدا Ollama در حال اجرا را از سینی ویندوز ببندید و سپس در پنجرهٔ PowerShell
زیر اجرا کنید:

```powershell
$env:OLLAMA_HOST = "127.0.0.1:11435"
ollama serve
```

تا زمانی که سرویس نیاز است این پنجره را باز نگه دارید. میزبان و درگاه
TheraSim را به `127.0.0.1` و `11435` تغییر دهید. برای استفادهٔ عادی، Ollama
را به `0.0.0.0` متصل نکنید و درگاه آن را در شبکهٔ محلی باز نگذارید. تغییر
درگاه فقط روی فرایندی اثر دارد که این متغیر محیطی را دریافت کرده است.

## ۶. GPU و حافظه

برای مشاهدهٔ محل اجرای مدل از `ollama ps` و برای بررسی حافظهٔ GPU از
`nvidia-smi` استفاده کنید. در رایانهٔ بررسی‌شده (۱۵٫۶ گیگابایت RAM،
پردازندهٔ Core i7-12650H و کارت RTX 3060 لپ‌تاپی با ۶ گیگابایت VRAM)،
`ollama ps` اجرای مدل آزمایش‌شده را ۱۰۰٪ روی GPU گزارش کرد. پس از آزمون
کوتاه، مصرف کل حافظهٔ GPU حدود ۲٫۱ گیگابایت بود. این فقط مشاهدهٔ همان مدل و
متن زمینه است، نه حداقل سخت‌افزار یا تضمین کارایی.

برای کاهش مصرف، مدل‌های بلااستفاده را از حافظه خارج کنید، مدل کوانتیزهٔ
کوچک‌تری انتخاب کنید، برنامه‌های سنگین GPU را ببندید و اندازهٔ متن زمینه را
بی‌دلیل افزایش ندهید. تنظیمات ارائه‌دهندهٔ فعلی TheraSim کنترل اندازهٔ متن
زمینه ندارد. افزایش متن زمینه می‌تواند مصرف حافظه را به‌طور محسوسی تغییر
دهد. مدل Q4 الزاماً دقیقاً یک‌چهارم حافظهٔ وزن‌ها را مصرف نمی‌کند.

## ۷. استفادهٔ آفلاین

- Ollama و مدل انتخابی را زمانی که اینترنت در دسترس است دریافت کنید.
- مدل را با `ollama list` بررسی و یک پاسخ محلی از آن دریافت کنید.
- پس از ذخیره‌شدن وزن‌ها، استنتاج محلی به اینترنت نیاز ندارد.
- بستهٔ آفلاین TheraSim و Ollama را اجرا کنید؛ ارائه‌دهنده باید به
  `127.0.0.1` اشاره کند و حالت فقط محلی روشن باشد.
- این موضوع نصب و دریافت اولیهٔ مدل را آفلاین نمی‌کند و کارکرد تمام وظایف
  سیستم‌عامل را بدون اینترنت تضمین نمی‌کند.

برای بررسی مقصد مدل در TheraSim، صفحهٔ **تنظیمات** را ببینید: ارائه‌دهنده
باید Ollama و نشانی پایه باید محلی باشد. هنگام درخواست، آزمایش اتصال و
`ollama ps` باید مدل محلی انتخاب‌شده را نشان دهند. بررسی به‌روزرسانی با
درخواست کاربر انجام می‌شود و برای شبیه‌سازی محلی لازم نیست. اگر اجرای کاملاً
محلی می‌خواهید، مدل ابری یا ارائه‌دهندهٔ دوردست انتخاب نکنید.

## ۸. خطاهای رایج

- **اتصال رد شد:** مطمئن شوید Ollama اجراست و این نشانی پاسخ می‌دهد:
  `http://127.0.0.1:11434/api/version`.
- **درگاه نادرست:** مقدار `OLLAMA_HOST` و تنظیمات TheraSim را مقایسه و نشانی
  دقیق `/v1/models` را آزمایش کنید.
- **مدل پیدا نشد:** `ollama list` را اجرا کنید و برچسب دقیق را دریافت یا در
  TheraSim اصلاح کنید.
- **مدل هست اما گفت‌وگو کار نمی‌کند:** اگر سرور از endpointهای گفت‌وگوی
  سازگار با OpenAI پشتیبانی نمی‌کند، Ollama را به‌روز کنید و دوباره آزمایش
  اتصال را انجام دهید. کلید را در گزارش یا خروجی پشتیبانی نگذارید.
- **کندی یا کمبود حافظه:** `ollama ps` و `nvidia-smi` را بررسی کنید، مدل‌های
  بلااستفاده را متوقف و مدل کوچک‌تری انتخاب کنید. مهلت پاسخ پیش‌فرض TheraSim
  ۱۲۰ ثانیه و مقدار مجاز آن ۱ تا ۶۰۰ ثانیه است.
- **پاسخ خالی:** بعضی مدل‌های استدلالی ممکن است بودجهٔ خروجی کوتاه را صرف
  محتوای پنهان کنند. از مدلی استفاده کنید که از API گفت‌وگوی پشتیبانی‌شده
  پاسخ متنی قابل‌نمایش برمی‌گرداند.
- **حالت فقط محلی نشانی را مسدود می‌کند:** مطمئن شوید میزبان واقعاً loopback
  است. برای رفع اشتباه تایپی، حالت فقط محلی را خاموش نکنید.

برای مشکل‌های خود برنامه، [راهنمای عیب‌یابی](TROUBLESHOOTING.fa.md) و
[راهنمای نصب ویندوز](../INSTALL_WINDOWS.md) را ببینید.
