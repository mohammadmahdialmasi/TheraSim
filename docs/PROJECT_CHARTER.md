# TheraSim
Psychotherapy Simulation & Training Platform

## Project Status
Research Prototype / Pre-MVP

## Vision
Develop an open-source, local-first, multilingual, multi-agent platform for simulating longitudinal psychotherapy sessions and providing evidence-based formative feedback to therapists.

## Core Problem
Psychotherapy trainees need opportunities to practice therapeutic interactions with realistic simulated clients and receive structured feedback across multiple sessions.

## Primary Users
- Clinical psychology students
- Psychotherapy trainees
- Early-career therapists
- Clinical supervisors
- Psychology researchers

## Primary Purpose
Educational simulation and psychotherapy skills training.

## Safety Boundary
This software is an educational simulation tool. It is not intended to diagnose, treat, or replace professional supervision or clinical judgment.

## Initial MVP Scope
- Therapeutic approach: ACT
- One fully fictional simulated client
- Sequential sessions created incrementally, with no universal fixed count
- Persian-first interaction
- Architecture prepared for English localization
- Local language model execution
- Patient Agent
- Evaluator Agent
- Structured Clinical State Engine
- Persistent session memory
- Evidence-linked session feedback
- Longitudinal performance reports

## Core Research Direction
Longitudinal Psychotherapy Simulation with Adaptive Patient Dynamics and Explainable Therapist Competency Assessment.

## Initial Technical Direction
- Python
- FastAPI
- React
- Ollama
- SQLite
- Pydantic
- Git

Technology choices may evolve during development.

## Core Design Principles
1. Local-first execution
2. Privacy by design
3. Synthetic clinical scenarios
4. Separation of simulation and evaluation
5. Evidence-grounded feedback
6. Cross-session consistency
7. Multilingual architecture
8. Reproducible testing
9. Modality-specific evaluation

## Initial Non-Goals
- Autonomous psychotherapy
- Real-client treatment
- Clinical diagnosis
- Professional licensing or certification
- Automated replacement of human supervisors
- Voice interaction in the first MVP

## Intellectual Property
The project will initially be developed privately. Public release and licensing will follow an intellectual property review.

## Long-Term Vision
Build an extensible research and educational platform supporting multiple psychotherapy modalities, languages, simulated clients, and validated assessment frameworks.
